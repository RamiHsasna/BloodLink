# BloodLink Import And Run

## Project Folder

Open this folder in IntelliJ IDEA:

`BloodLink-LogManagement`

## What Is Included

- project-local PostgreSQL driver in `.deps`
- project-local JavaFX jars in `.deps/javafx`
- shared IntelliJ libraries in `.idea/libraries`
- shared IntelliJ run configuration in `.run/BloodLink.run.xml`

This means another machine does not need your local `Downloads` folder paths to run the app.

## IntelliJ Steps

1. Open the project folder in IntelliJ IDEA.
2. Let IntelliJ trust the project.
3. If IntelliJ asks for a JDK, choose Java 21 or newer.
4. Open the run configuration named `BloodLink`.
5. Run `BloodLink`.

## Main Class

The entry point is:

`src/WorkshopJDBC/Main.java`

Main class:

`WorkshopJDBC.Main`

## Notes

- The project uses Supabase PostgreSQL through the connection defined in `config.properties` and the datasource classes under `src/tn/edu/esprit/Tools`.
- `out/` is build output only and can be regenerated by IntelliJ.
- `Blood Types` is still a placeholder module in this codebase.
